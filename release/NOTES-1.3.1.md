## BatteryTray 1.3.1

Windows 托盘电量显示工具 —— 让鼠标、键盘和耳机的电量一眼可见。

### 下载

| 版本 | 文件 |
|------|------|
| 安装版（推荐） | `BatteryTray-Setup-1.3.1.exe` — 带安装向导、开始菜单快捷方式和卸载程序 |
| 便携版 | `BatteryTray-1.3.1-portable.zip` — 解压即用 |
| 单文件版 | `BatteryTray-1.3.1.exe` — 双击即运行，免安装 |

### 修复：检查更新的窗口和主界面不是一个样子

之前「检查更新」的窗口用的是另一套配色和另一套按钮 —— 背景是接近纯黑的 `#111113`，按钮是 Windows 默认的直角灰按钮，强调色是刺眼的纯绿 `#00E676`，跟主界面那种柔和的深蓝灰完全对不上。看起来像是另一个软件弹出来的。

现在这个窗口跟主界面、跟「设置」窗口用的是同一套了：

- **同一套配色** —— 背景、卡片、边框、文字全部改用主界面的颜色；刺眼的纯绿换成了柔和的绿
- **同样的圆角按钮** —— 「立即更新」「下载安装包」「关闭」都换成了主界面那个圆角样式，鼠标移上去会变色
- **同样的排版** —— 圆形图标 + 标题 + 说明在上，内容装在圆角卡片里，按钮在底栏
- **发行说明**也放进了圆角的输入框里，跟设置窗口里的输入框一致

顺手修掉了两个自己长不高的问题：窗口以前是塌成一条 1 像素的细线，现在内容多了就变高、内容少了就收窄，不再卡在第一次布局的高度。

### 功能

- **二十多种厂商协议** —— Compx / AULA / Keychron / Pulsar / MCHOSE / Lamzu / Ninjutso / Bloody / HyperX / SteelSeries / 雷柏 / Attack Shark / Lofree / NZXT / ASUS ROG 键盘与 Omni 接收器等
- **型号名称库** —— 托盘上显示「Lofree Hyzen 无线键盘」而不是 `USB Composite Device`
- **多品牌电量** —— 罗技、ATK/VXE/VGN、Endgame、VAXEE、Nordic、ROG、雷蛇
- **颜色即状态** —— 绿 ≥60% / 橙 20–59% / 红 <20% / 蓝=充电中 / 灰=离线
- **应用内检查更新** —— 托盘菜单或主窗口底部都能触发，新版本可以直接下载安装并自动重启
- **左键浮层 / 右键菜单 / 低电量通知 / 自定义设备名 / 开机自启**

### 系统要求

- Windows 10 / 11
- 无线接收器需要保持插着
- 蓝牙耳机需主动上报电量（HFP）
- 键盘默认不显示，需要在设置里勾选「键盘」

### 已知限制

- 新增品牌目前只读取电量，DPI / 回报率 / 改键仍只对雷蛇和 ROG 月刃开放
- 部分键盘（如 Lofree、Keychron）休眠时不响应查询，按一下键盘再刷新即可
- 罗技蓝牙 BLE 直连不走 HID++，由 Windows 蓝牙属性读取
- 电量为原始刻度换算值，实际可能有 ±2% 误差
- 蓝牙设备离线时显示「未连接」，重新开机后需等设备上报一次电量才恢复
- 自动更新只替换单文件版；从安装版或源码运行时请用下载页面手动替换
