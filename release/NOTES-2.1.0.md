# BatteryTray 2.1.0

低电量提醒换成了应用自己的卡片。

## 一、提醒不再是一个灰气泡

以前的提醒是 `win10toast` 弹出来的老式托盘气泡，Windows 把它当成本进程的通知：

- 标题栏写着 **Python**，不是 BatteryTray
- 文案是英文的 `Battery low` / `Razer Viper V3 Pro Wireless is at 12%`
- 图标加载失败（`LoadImage` 读不了 PNG），干脆什么图标都没有

现在提醒画成和主界面一样的卡片：

- 深色圆角卡片，和第二版界面的卡片同一个颜色、同一个电池图标
- 中文文案：设备名 + 「电量低，只剩 12%」，电量数字就是卡片里那颗小电池上的数字
- 出现在任务栏通知区上方，7 秒后自己淡出消失
- 点一下直接打开主界面；同时有第二个设备也低电量时，卡片换成那个设备，不会叠一堆

## 二、提醒在界面线程里画

`_check_low_battery` 跑在轮询线程里，而这个卡片是 tkinter 窗口 —— tkinter 只能
在拥有它的线程里画。所以提醒现在经由 `_post_to_window` 交给界面线程创建/更新，
和更新对话框的进度回调走同一个通道。

`win10toast` 这个依赖随之去掉（`requirements.txt`、`BatteryTray.spec` 里的
`hiddenimports` 都清了），顺手也去掉了每次启动往配置目录写一张 `batterytray.png`
的动作 —— 那是老气泡用的图标，现在不需要了。

## 验证

`verify_all.py` **293 项通过**，本轮新增 4 项：

- 提醒用的是主界面的配色和边框，文案里有设备名和「电量低…12%」，位置在屏幕右下
- 提醒会自己关掉，不会一直留在桌面上
- 点提醒会打开主界面
- 低电量是在轮询线程里发现的，但提醒必须在界面线程里建（假窗口记录排队情况）

另外用 `tools/render_toast.py` 渲染了卡片本身，并在真机上把阈值临时调到 100
触发了一次，确认它落在通知区上方、圆角、边框和卡片位置都对。

## 更新

从 2.0.1 起更新流程已经干净，可以直接在软件里点更新；2.0.0 及更早的版本更新
时仍会弹一次 `Failed to load Python DLL`，点确定后从开始菜单重新打开即可。
