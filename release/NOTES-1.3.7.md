# BatteryTray 1.3.7

这一版改的是窗口的层级：**程序自己的窗口不再永远压在别人上面，可以被盖住。**

## 以前为什么置顶

托盘图标的电量浮窗是没有边框的弹窗，而设置、更新、诊断、重命名、鼠标参数
这些对话框都从它或者托盘菜单里打开。为了不让对话框被那个浮窗挡住，对话框
一律设成了置顶（`-topmost`）；浮窗本身也是置顶的。

问题是这个「置顶」是**常驻**的：只要窗口开着，就永远在最前面，想切到别的
程序对照着看都不行。

## 现在

- **对话框**（设置 / 检查更新 / 诊断 / 重命名 / 鼠标参数）：不再置顶。打开
  时仍然会到前台（`lift`），之后就是普通窗口，点别的程序就能盖住它。
- **托盘电量浮窗**：创建时不再置顶；显示的那一刻会临时置顶 80 毫秒把自己
  带到前台，随后立刻取消。这样它还是会在你点托盘图标时正确地出现在最前面，
  但之后可以被别的窗口覆盖。

## 验证

`verify_all.py` **285 项通过**，新增 2 项：

- 对话框打开后 `-topmost` 必须是 0
- 浮窗创建时、以及显示之后 `-topmost` 都必须是 0

把这两个文件换回上一版，这两项立刻失败 —— 说明测的是真行为，不是文字。
