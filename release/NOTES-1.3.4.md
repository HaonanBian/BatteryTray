# BatteryTray 1.3.4

这一版把主屏幕收拾干净了，也让鼠标参数设置窗口可以自由拉伸。

## 主屏幕

主窗口右下角以前有四个按钮：设置、刷新、检查更新、诊断。

现在**诊断按钮从主屏幕上撤掉了**，只留三个：

| 按钮 | 作用 |
|------|------|
| 设置 | 打开设置窗口 |
| 刷新 | 立刻重新读一遍设备 |
| 检查更新 | 看看有没有新版本 |

诊断的报告没有丢，它挪到了**设置窗口**里 —— 底部还有一个「诊断」按钮，
上面也有一行字提示「设备读不到时，用下方的「诊断」按钮把报告发给我」。

放在设置窗口更合适：那本来就是排查设备问题时会去的地方，
主屏幕上少一个按钮，看起来也干净些。

## 鼠标参数设置窗口

以前这个窗口是锁死大小的，鼠标参数设置里面的 DPI 挡位和按键映射
一多就装不下，只能看到上面一半。

现在**可以随便拖动边框调整大小**：

- **拖大** —— 内容跟着铺开，DPI 预设按钮排成四列
- **拖小** —— 右边出现滚动条，用滚轮往下翻
- **DPI 预设按钮**改成网格排列，窗口变窄时会自动换行，
  不会挤成一团或者被挤出边界
- **数字输入框上滚轮只翻页**，不会不小心把 DPI 数值改掉
- 窗口**居中时按实际大小算**，不会因为鼠标刚读出来、内容突然变高
  而跳一下

最小尺寸是 460×400，再小就没法用了。

## 其他

- 主窗口去掉诊断按钮，诊断入口保留在设置窗口
- 鼠标参数设置窗口可以自由拉伸，内容用滚动条翻页
- DPI 预设按钮改成网格排列，变窄时自动换行
- 数字输入框上的滚轮不再改动数值
- 窗口居中按实际尺寸计算，读鼠标时不再跳动
