## BatteryTray 1.3.0

Windows 托盘电量显示工具 —— 让鼠标、键盘和耳机的电量一眼可见。

### 下载

| 版本 | 文件 |
|------|------|
| 安装版（推荐） | `BatteryTray-Setup-1.3.0.exe` — 带安装向导、开始菜单快捷方式和卸载程序 |
| 便携版 | `BatteryTray-1.3.0-portable.zip` — 解压即用 |
| 单文件版 | `BatteryTray-1.3.0.exe` — 双击即运行，免安装 |

### 新增：应用内检查更新

点托盘菜单里的「检查更新」，或者点主窗口底部的「检查更新」按钮，就会去 GitHub 上看有没有新版本：

- **自动比对版本号** —— 比对的是 GitHub Release 的 tag 和当前运行的版本
- **新版本直接装** —— 点「立即更新」就会下载并自动替换当前这份程序，装完自动重启，不用手动去下载
- **装不了也能看** —— 如果当前是从源码运行的，会提示去下载页面手动替换
- **不会烦你** —— 检查是在后台线程里跑的，界面不会卡住；已经是最新版本时直接告诉你

### 新增：弹窗改成系统设置那种面板

「设置」和「检查更新」两个窗口换成了系统设置里的分组面板样式：

- 圆角徽章图标 + 标题 + 说明，下面是分组的卡片
- 下载的时候有进度条，装完会显示「正在重启…」
- 版本号、发行说明直接列在卡片里

深色配色保持不变，只是排版跟系统面板一致。

### 修复

- **窗口缩到最小时底部按钮不见了** —— 之前设备列表会把「刷新」「设置」挤出窗口，现在这两个按钮（以及新增的「检查更新」）在任何尺寸下都固定在底部可见
- **设置里的文字错字** —— 「电量低于或等于该值时弹出通知」

### 功能

- **二十多种厂商协议** —— Compx / AULA / Keychron / Pulsar / MCHOSE / Lamzu / Ninjutso / Bloody / HyperX / SteelSeries / 雷柏 / Attack Shark / Lofree / NZXT / ASUS ROG 键盘与 Omni 接收器等
- **型号名称库** —— 托盘上显示「Lofree Hyzen 无线键盘」而不是 `USB Composite Device`
- **多品牌电量** —— 罗技、ATK/VXE/VGN、Endgame、VAXEE、Nordic、ROG、雷蛇
- **颜色即状态** —— 绿 ≥60% / 橙 20–59% / 红 <20% / 蓝=充电中 / 灰=离线
- **左键浮层 / 右键菜单 / 低电量通知 / 自定义设备名 / 开机自启**

### 系统要求

- Windows 10 / 11
- 无线接收器需要保持插着
- 蓝牙耳机需主动上报电量（HFP）
- 键盘默认不显示，需要在设置里勾选「键盘」

### 已知限制

- 新增品牌目前只读取电量，DPI / 回报率 / 改键仍只对雷蛇和 ROG 月刃开放
- 部分键盘（如 Lofree、Keychron）休眠时不响应查询，按一下键盘再刷新即可
- 罗技蓝牙 BLE 直连不走 HID++，由 Windows 蓝牙属性读取
- 电量为原始刻度换算值，实际可能有 ±2% 误差
- 蓝牙设备离线时显示「未连接」，重新开机后需等设备上报一次电量才恢复
- 自动更新只替换单文件版；从安装版或源码运行时请用下载页面手动替换
