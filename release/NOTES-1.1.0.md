## BatteryTray 1.1.0

Windows 托盘电量显示工具 —— 让鼠标、键盘和耳机的电量一眼可见。

### 下载

| 版本 | 文件 |
|------|------|
| 安装版（推荐） | `BatteryTray-Setup-1.1.0.exe` — 带安装向导、开始菜单快捷方式和卸载程序 |
| 便携版 | `BatteryTray-1.1.0-portable.zip` — 解压即用 |
| 单文件版 | `BatteryTray-1.1.0.exe` — 双击即运行，免安装 |

### 新增

- **罗技 HID++ 2.0** — 支持 Unifying / Bolt 接收器下的罗技无线鼠标和键盘，读取电量、充电状态和 HID++ 设备名
- **ATK / VXE / VGN** — 两种 Nordic 2.4G 方案
- **VXE V75 Pro 键盘** — 发送 `04 1A 06` 状态请求，从回复第 8 字节读取电量、第 9 字节读取充电状态
- **Endgame Gear** — XM2w / OP1W 等接收器
- **VAXEE / ZYGEN** — 含 4K 接收器
- **Nordic nRF 通用 2.4G** — 常见白牌接收器
- **ROG 月刃无线 AimPoint** — 修正 HID 报文长度、接口选择和事件回包过滤；USB/2.4G 下可改 DPI、回报率和按键
- **界面清理** — 去掉设备卡片和托盘浮层上的铅笔图标，只保留齿轮设置入口
- 安装向导副标题改为「鼠标、键盘与耳机电量」，并修复 `uninstall.exe` 直接启动时进入安装界面而不是卸载界面的问题

### 功能

- **雷蛇鼠标免驱动读取** — 直接通过 USB HID feature report 读取电量
- **多品牌电量** — 罗技、ATK/VXE/VGN、Endgame、VAXEE、Nordic、ROG、雷蛇
- **颜色即状态** — 绿 ≥60% / 橙 20–59% / 红 <20% / 蓝=充电中 / 灰=离线
- **左键浮层 / 右键菜单 / 低电量通知 / 自定义设备名 / 开机自启**
- **正确识别离线设备** — 不会把缓存的旧电量当成当前电量

### 系统要求

- Windows 10 / 11
- 无线接收器需要保持插着
- 蓝牙耳机需主动上报电量（HFP）
- 罗技键盘默认不显示，需要在设置里勾选「键盘」

### 已知限制

- 新增品牌目前只读取电量，DPI / 回报率 / 改键仍只对雷蛇和 ROG 月刃开放
- 罗技蓝牙 BLE 直连不走 HID++，由 Windows 蓝牙属性读取
- 电量为原始刻度换算值，实际可能有 ±2% 误差
- 蓝牙设备离线时显示「未连接」，重新开机后需等设备上报一次电量才恢复
