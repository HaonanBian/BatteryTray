## BatteryTray 1.0.0

Windows 托盘电量显示工具 —— 让鼠标和耳机的电量一眼可见。

### 下载

| 版本 | 文件 |
|------|------|
| 安装版（推荐） | `BatteryTray-Setup-1.0.0.exe` — 带安装向导、开始菜单快捷方式和卸载程序 |
| 便携版 | `BatteryTray-1.0.0-portable.zip` — 解压即用 |
| 单文件版 | `BatteryTray-1.0.0.exe` — 双击即运行，免安装 |

### 功能亮点

- **雷蛇鼠标免驱动读取** — 直接通过 USB HID feature report 读取电量，不需要装 Synapse，不需要内核驱动，不需要管理员权限
- **蓝牙耳机电量** — 通过 Windows 蓝牙协议栈读取
- **颜色即状态** — 托盘闪电图标按电量变色：绿 ≥60% / 橙 20–59% / 红 <20% / 蓝=充电中 / 灰=离线
- **左键浮层** — 无边框面板一眼看完所有设备电量，点击别处自动收起
- **深色主窗口** — 雷蛇风格卡片 + 环形电量表，支持自定义设备名称
- **右键菜单** — 查看电量 / 打开主窗口 / 立即刷新 / 设置 / 开机自启 / 打开启动文件夹 / 退出
- **低电量通知** — 阈值可调（1–100%）
- **设备类型筛选** — 鼠标 / 耳机 / 游戏手柄 / 键盘
- **正确识别离线设备** — 修复了「耳机没连却一直显示 100%」这个经典 bug
- **单实例运行** — 重复点击不会堆叠托盘图标
- **免安装** — 纯用户态，不写注册表、不装服务

### 系统要求

- Windows 10 / 11
- 雷蛇无线鼠标需保持接收器插着
- 蓝牙耳机需主动上报电量（HFP）

### 已知限制

- 电量为原始刻度换算值，实际可能有 ±2% 误差
- 雷蛇耳机（Kraken / BlackShark）使用独立厂商协议，未纳入本版本
- 蓝牙设备离线时显示「未连接」，重新开机后需等耳机上报一次电量才恢复
