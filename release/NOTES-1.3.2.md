### 修复：点「立即更新」一直失败

这是 1.3.1 最严重的问题，从发布的第一天就存在，现在彻底修好了。

**问题的根源在发布环节，不在程序里。** 上传到 GitHub 的三个附件外面被套了一层 HTTP multipart 的外壳：

```
------BatteryTrayUploadBoundary7f3a9c1e
Content-Disposition: form-data; name="file"; filename="BatteryTray-1.3.1.exe"
Content-Type: application/octet-stream

MZ......真正的程序内容在这里......
------BatteryTrayUploadBoundary7f3a9c1e--
```

GitHub 收下了这些文件（状态显示「已上传」、大小也对得上），但它把外壳一起存了进去。于是用户点「立即更新」时，程序下载回来的东西开头是 `------Battery...` 而不是 `MZ`，Windows 根本认不出这是可执行文件，替换之后自然启动不了。

外壳正好 207 字节 —— 这也解释了为什么 GitHub 上的文件比本地的每个都大 207 字节。

**现在已经做三件事：**

1. **重新发布了完好的附件** —— 三个文件都改用原始字节上传，现在线上文件和本地文件的 SHA-256 完全一致，下载下来开箱即用
2. **下载加了自动重试** —— 连接 GitHub 的 CDN 时偶尔会掉线重连，之前一次失败整个更新就报废了；现在会重试 3 次，退避时间逐次拉长
3. **下载后先验明正身** —— 拿到文件先检查开头是不是 `MZ`，不是就直接拒绝并给出明确提示，绝不会把一个坏文件放到正在运行的程序旁边

顺带修掉的还有：

- **重试时界面不再像卡死** —— 现在会显示「第 N 次下载失败（原因），正在重试…」，进度条回到起点重新开始
- **失败后不留垃圾** —— 之前每次失败都在程序目录里留下一个 256KB 的 `batterytray-download-xxxx` 临时文件，现在失败即清理
- **没权限时说实话** —— 程序装在需要管理员权限的文件夹里时，现在会明确提示「请以管理员身份运行」，而不是关掉程序后什么也不发生

### 验证方式

修完之后跑了完整的端到端测试：从 GitHub 拉取 → 下载 → 校验 → 关闭程序 → 交换文件 → 新版就位，全流程通过，下载到的文件大小 19,255,559 字节、以 `MZ` 开头。

### 功能

- **二十多种厂商协议** —— Compx / AULA / Keychron / Pulsar / MCHOSE / Lamzu / Ninjutso / Bloody / HyperX / SteelSeries / 雷柏 / Attack Shark / Lofree / NZXT / ASUS ROG 键盘与 Omni 接收器等
- **型号名称库** —— 托盘上显示「Lofree Hyzen 无线键盘」而不是 `USB Composite Device`
- **多品牌电量** —— 罗技、ATK/VXE/VGN、Endgame、VAXEE、Nordic、ROG、雷蛇
- **颜色即状态** —— 绿 ≥60% / 橙 20–59% / 红 <20% / 蓝=充电中 / 灰=离线
- **应用内检查更新** —— 托盘菜单或主窗口底部都能触发，新版本可以直接下载安装并自动重启
- **左键浮层 / 右键菜单 / 低电量通知 / 自定义设备名 / 开机自启**

### 系统要求

- Windows 10 / 11
- 无线接收器需要保持插着
- 蓝牙耳机需主动上报电量（HFP）
- 键盘默认不显示，需要在设置里勾选「键盘」

### 已知限制

- 新增品牌目前只读取电量，DPI / 回报率 / 改键仍只对雷蛇和 ROG 月刃开放
- 部分键盘（如 Lofree、Keychron）休眠时不响应查询，按一下键盘再刷新即可
- 罗技蓝牙 BLE 直连不走 HID++，由 Windows 蓝牙属性读取
- 电量为原始刻度换算值，实际可能有 ±2% 误差
- 蓝牙设备离线时显示「未连接」，重新开机后需等设备上报一次电量才恢复
- 自动更新只替换程序本体；从源码运行时请用下载页面手动替换
